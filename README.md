    <h1 align="center">Parsa Portfolio</h1>

A simple personal portfolio built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).

</div>

<br/>

## Running Locally

```sh-session
git clone https://github.com/parsa/Parsa.git
cd Parsa
```

Install dependencies and run the development server:

```sh-session
pnpm install
pnpm dev
```
